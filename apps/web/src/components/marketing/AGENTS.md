# Public marketing components

These instructions supplement the repository-level `AGENTS.md` for this directory.

- Read the brand, design-system, responsive, voice, claims, SEO, and relevant content
  documents before changing UI or copy.
- Reuse the existing tokens, components, and approved brand assets. Do not reconstruct
  the SDK wordmark or compact mark as text.
- Never invent clients, metrics, testimonials, outcomes, awards, certifications, or
  company history.
- Keep meaningful content and crawlable links in Server Components. Limit client-side
  JavaScript to required interaction.
- Preserve semantic structure, keyboard access, visible focus, contrast, stable layout,
  responsive content parity, localized metadata, and accurate image alternatives.
